## General Course Materials

Course-wide resources are stored in [`general/`](./general/).

Typical contents include:

```text
general/
├── syllabus/
├── templates/
├── [...]
```

## Modules

Each course module has its own directory and follows the structure laid out by the instructor. The following is an example of what these folders *might* include:

```text
module-01/
├── README.md
├── assignments/
├── exercises/
└── projects/
```

Module README files, *if present*, provide additional information about the material and assignments contained within that module.

## Repository Conventions

Directories that do not yet contain coursework may include a `.gitkeep` file so that the directory structure remains visible in Git.

Generated files, IDE configuration, compiled output, and locally installed dependencies are excluded through the repository's `.gitignore`.

Dependency definition files such as `package.json`, `pom.xml`, `requirements.txt`, or equivalent configuration files should remain committed so that the development environment can be recreated locally.
